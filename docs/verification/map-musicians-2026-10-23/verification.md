# 自定义地图音乐家实施与验收

## 使用方式

教师登录后进入 `/map`，点击右上“添加音乐家”，在当前中国或欧洲底图的空白位置选点，再填写姓名、地区、时代和简介。年代、代表作、学习提示、头像及资料来源可选。地图可以先缩放、平移后选点；保存后自动选中新增人物并展示资料卡。

创建者教师可从人物卡“编辑音乐家”，修改资料、替换/移除头像或“重新选点”；删除须二次确认。学生可查看资料、头像、来源并提问，没有增删改入口；服务端也拒绝学生写入、其他教师修改和内置人物修改。

选点期间暂时禁用地图、时代、编辑和删除按钮，避免未保存草稿被覆盖；取消选点可退出。上传和保存期间锁定表单，防止重复提交。文件清理失败但资料已成功保存/删除时，返回成功及明确提示，不自动重发写入。

## 数据与权限

- 内置人物继续使用 `src/lib/composers.ts`，不改原人物数据。API将旧正方形示意点位换算至完整底图，自定义点位直接保存为完整底图0–100%的位置，兼容缩放和平移。点位是地域示意，不是真实经纬度。
- 新增 `map_musicians` 表、`/api/map-musicians` 认证读取和教师CRUD，前端合并显示内置及自定义人物。保存到数据库，刷新后保留。
- 本地新库及已有数据库自动创建新表；不清空原有数据。远程 schema、`0008_map_musicians.sql`、journal及snapshot同步，RLS和表权限只允许服务端 `service_role` CRUD。远程部署须先应用迁移；本轮未执行线上迁移。
- 头像保存 `avatar_file_id`，复用上传和签名文件读取。仅被人物引用的头像向其他登录用户开放；其他私人上传保持原访问规则。替换/删除时检查所有业务引用，避免误删仍在使用的文件。
- 专用头像上传使用 `purpose=map-avatar`，校验教师身份、栅格文件头与MIME。远端新头像要求带相同用途的服务端签名凭证，普通琴谱上传及旧琴谱凭证保持兼容。本地头像还验证文件所有权和文件头。
- 单个头像丢失或续签失败会回退为空头像，由页面显示姓名首字，不阻断人物列表。
- 人物讲解按服务端ID读取当前数据库资料，删除后不再作为讲解依据；只向模型发送姓名、年代、时代、地区、简介、作品、学习提示与来源，不发送教师身份、头像编号或签名头像URL。
