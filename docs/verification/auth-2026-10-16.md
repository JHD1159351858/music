日期：2026-10-16。当前服务：http://localhost:5000/，Next.js 生产构建。

以下初次验收保留为历史记录；当日后续接入已部署认证中心的最新结果见文末「真实认证中心接入补充」。

## 已实现

- 默认匿名，移除浏览器旧昵称身份；首页各模块、AI 助教和业务 API 均要求服务端签名会话。
- 按用户提供的认证中心源码协议完成跳转、state 校验、一次性 ticket 后端验证和稳定用户映射。学生不能通过请求参数冒用教师身份。
- 教师通过超星身份验证后仍无业务权限，完成独立安全密码校验才建立会话；密码只在后端配置，连续错误有限流。
- 写请求检查 Origin；退出清理会话。会话使用 HttpOnly Cookie，不保存于 localStorage。
- 桌面首页使用完整图随窗口拉伸铺满，取消模糊余区；窄高窗口会改变画面比例。
