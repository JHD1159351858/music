# 多页琴谱实施计划

**目标：** 一份琴谱可保存有序的多张图片，上传、编辑、预览、沉浸练习完整可用。

**方案：** 新增可选 `pages` JSON 数组，每页包含 `file_id/image_url/file_name/file_type`；原单文件字段保留为首页兼容字段。旧琴谱读取时按单页处理。教师 PDF 继续作为一个文件展示，图片多页不混入 PDF。最多 50 张图片，单文件沿用 100MB 限制。

**约束：** pnpm、现有主题与 shadcn 组件；保留教师发布班级范围、学生私有权限、已有批量独立曲目上传、录音和计时行为。只修改相关文件，不提交仓库现有改动。

- [x] 存储和接口：先补接口回归，验证多页往返顺序、逐页权限校验、签名链接续签、移除页面后的引用清理以及旧单页兼容；再实现本地自动迁移、远程迁移、类型、校验、CRUD 和文件访问控制。
- [x] 上传和编辑：默认多选图片归为一份琴谱；保留批量独立琴谱模式；页面可追加、上移、下移、移除；已上传页面在失败重试时不重复上传。
- [x] 看谱：公共分页控件用于预览和练习；切换时页码明确，当前页适应屏幕；专注看谱保留分页入口，翻页不重启练习计时/录音。曲库显示页数，使用第一页作为封面。
- [x] 最终验证：定向接口与文件权限测试、修改文件 ESLint、生产构建；重启本地服务后浏览器上传两页，调整顺序、保存、重新打开、预览/练习翻页、缩放、专注模式。保留两页测试琴谱作为可复查样例。

权限复查补充：远端琴谱上传返回仅上传者持有的签名凭证（7 天），保存每页时验证文件编号、上传者与服务端 MIME，凭证不入库。已有远端谱页按本人持有的数据库引用兼容。相同 UUID 的 POST 重试若更改页序或内容，返回明确冲突，避免误报保存成功。
