# 知音教学需求改造实施计划

**目标**：以《知音教学智能体学生端与教师端需求笔记》为验收依据，补齐可独立落地的功能和真实使用链路，保留明确待确认的外部能力边界。

**架构**：沿用 Next.js、服务端签名会话、统一数据库入口、本地 SQLite/远程 schema 双模式。保持当前深色音乐厅视觉与 shadcn 组件，不覆盖工作区已有修改。

## 本次设计与范围

- 琴谱按每份资源选择全部班级或指定班级；空班级范围保留已有全部班级语义。学生自传琴谱固定私有，不能发布。
- 练习记录使用昵称，沿用有效秒数、暂停次数及持久 fileId；补齐上传保存、续签、删除链路。
- 社区公开求助与直接教师留言分开；直接留言仅发件学生及收件教师可见。回课标记按教师独立保存。
- 课程知识由教师维护标题、内容、检索词及参考链接。回答引用实际收录内容；未匹配时明确超出范围。
- 乐谱指标取消节奏密度，结构化记谱优先真实解析。图片视觉结果明确为模型识别；不能可靠解析的数据保留空值并显示未识别。
- 地图沿用中国优先及中欧一致交互，补来源、同期中国提示和筛选状态修复。

## 实施分组与验收

- [x] 谱库与练习：学生自传、班级发布范围、放大/全屏、档案字段、本地上传保存、文件归属与删除。权限、录音与文件回归通过。
- [x] 任务与统计：学生只看本人统计，教师按周期查看班级数据；材料提交、评阅和统计公式验证通过。
- [x] 社区与地图：私信、独立回课标记、完整清单导出、排序、答疑入口、史实来源与中外对照。私信隔离与导出通过。
- [x] 知识库与分析：教师知识 CRUD、服务端检索、受资料约束的 SSE、真实指标解析和未识别状态。解析/权限/空结果通过；外部模型实际调用返回不可用，保留该边界。
- [x] 集成：TypeScript、ESLint、82项测试、Next 构建、35项HTTP回归和9组浏览器流程通过；截图和真实服务边界已记录。

## 保留为待确认或外部验证

游客访问范围、Word 转谱图、目标学习通浏览器的 PDF/麦克风/视频兼容、学习通消息推送、学校分析指标清单、后续开源模型和真实统一认证平台联调。不给这些项目填造完成状态。
