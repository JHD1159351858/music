# 超星登录与教师二次验证实施计划

**目标：** 默认匿名，所有模块需超星登录，教师再通过服务端安全密码验证；首页取消模糊填充，完整图按窗口拉伸。

**架构：** 复用用户提供的「超星登录认证系统」票据协议，知音仅作为接入站点；浏览器跳转认证中心，知音后端以共享密钥验票，签发 HttpOnly 会话。沿用现有 profiles 与业务 API，业务身份绑定会话而非请求 user_id。

**约束：** pnpm；无真实登录前不得授予演示身份；密钥只在后端；不存真实姓名；不删除旧业务数据；不把测试认证中心描述成真实超星。
