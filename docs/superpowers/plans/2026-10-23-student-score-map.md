# 学生入口、琴谱分类与音乐史地图调整

**Goal:** 按本次需求调整学生入口、统一悬浮答疑、替换琴谱分类维度并扩大地图可视范围。

**Architecture:** 复用签名会话、课程知识 API、SSE ChatPanel 与现有地图静态人物。学生助手置于根布局，跨学生路由保留会话；教师知识管理保持原入口。分类采用新增列的非破坏迁移，保留历史列但停止在产品中使用。

**Tech Stack:** Next.js 16、React 19、TypeScript、shadcn/ui、SQLite / Supabase、pnpm。

## 约束与具体选择

- 查询曲库以新窗口打开 https://imslp.org，保留当前上传和群组操作。
- 学生撤下独立课程知识与答疑导航；旧链接转到首页并打开助手。助手含答疑及课程资料检索，教师继续维护知识库。
- 类型包含协奏曲、圆舞曲、夜曲、弹奏曲、练习曲、奏鸣曲、前奏曲、赋格、变奏曲、其他。时期支持世纪或历史阶段文字。
- 旧谱不猜填新分类；本地新库、旧库增量迁移及远程 Drizzle schema/迁移同步更新。保留班级范围、私人谱图权限与多页文件顺序。
- 地图页独立收窄导航；时代工具栏横排、地图扩大，人物卡与地图位于同一面板，讲解按需展开。人物自定义仅评估。
- 仅使用语义主题变量、现有地图和头像资源；不扩展未要求的群组功能或全站重设计。
