# 琥珀音乐厅全模块实施计划

> **For agentic workers:** 执行 subagent-driven-development；各代理限定文件所有权，集成后统一验证。

**Goal:** 按已批准的10张设计图改造现有项目，并实现独立曲目封面和选中展示。

**Architecture:** 保留Next.js现有路由、真实API、身份与业务权限。以学生/教师主题壳和模块样式实现视觉统一；封面新增可空fileId，走现有受控上传、签名下载和引用清理，旧曲目使用主题图片兜底。

**Tech Stack:** Next.js 16、React 19、TypeScript、shadcn/ui、Tailwind 4、SQLite / Drizzle；仅pnpm。

## 约束与验收

- 依据 docs/design/2026-10-27-amber-concert-hall 中最终版本实施，学生暖黑金、教师深侧栏暖白正文。
- 图中演示数字不写入业务页面或当前数据；不增加评分维度、排行榜、MIDI判音等设计稿外功能。
- 曲目封面与真实谱面分离，封面选中不影响查看谱面、待练列表和开始练习；真实录音、提交、评阅、地图缩放保留。
- 所有新增封面字段同时更新本地新库/旧库、远程schema/迁移与权限测试；客户端不提交可信身份或任意封面URL。
- 主页面及手机端不溢出，主要控件可见可操作；新增持续动效有暂停/减少动效支持。
- 不部署或推送；本地启动真实项目供用户查看。

## 实施分工

- [x] 独立封面：teaching-types / validation / files / server、scores / upload / files API、ScoreEditor、0010迁移；验证存取、权限、共享清理、旧库和损坏封面。
- [x] 资源与展示：生成月夜、雨夜、田野和练习琴房独立图片到public/covers，建立score-cover helper和ScoreCover组件，真实封面失败可回退。
- [x] 主题壳：首页与学生导航统一黑金；教师AdminShell/AdminTable/统计和筛选统一暖白；所有页面沿用原权限。
- [x] 曲库：真实筛选结果中选择曲目，同步独立封面大图、曲名、作曲家、练习入口；保留个人上传、查看、队列、档案、删除。
- [x] 学生模块：分析、任务与提交、社区、地图、统计、沉浸练习、课程助手按所选图实施。
