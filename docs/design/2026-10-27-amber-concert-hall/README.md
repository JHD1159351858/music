# 知音 · 琥珀音乐厅全模块设计预览

本套方案延续已选定的第一张「琥珀音乐厅」方向，含 **10 张成组设计图、20 个页面／关键状态**，并保留最初的学生曲库＋教师教学概览图作为风格基准。这里是视觉设计稿，尚未实施页面改造。

学生页面采用暖黑音乐厅、琥珀金、衬线标题与浅色正文；教师后台采用同品牌深色侧栏、暖白正文和清晰的表格。历史人物资料、统计口径、权限和提交字段在实施时继续采用现有项目定义，图中小字及数据仅用于排版示例。

## 曲目封面与选中逻辑

- 每首曲目使用独立封面图；封面与谱面是两个不同资源。
- 月光奏鸣曲采用月夜湖面，降E大调夜曲采用雨夜暖窗，牧童短笛采用田野与芦苇意象；三张仅为美术方向示例，不是全曲库成品资产。
- 点击曲目封面或选择该曲目时，上方主视觉同步更新封面、曲名、作曲家及开始练习所指向的曲目。
- 同一曲目的封面在曲库、任务、练习抬头、档案、教师琴谱管理中保持一致。
- 沉浸练习仍以真实谱面为主体，封面仅用于曲目标识。
- 教师设计稿中增加了独立的封面图维护位置；当前代码尚无独立封面字段，具体字段、存储与旧曲目补图将在实施阶段处理。

## 功能边界

- 乐谱分析是乐谱结构识别，不是演奏自动打分；图片识别需要复核。
- 教师评阅保持单一 0–100 整数评分和文字评语。学生只能提交材料、查看教师评分。
- 评阅中的练习记录沿用现有关联记录；图中的文件图标与文件名仅作排版示例，不新增练习记录 PDF 上传接口。
- 学生音乐史地图只读；自定义音乐家仅教师可添加和管理。地图史实、年代、人物与来源以现有资料为准，生成图中文字不是新的史实依据。
- 教师课程知识维护标题、正文、关键词和参考链接；不新增文件训练流程。图中的知识条目插图是美术示意，不表示新增封面上传字段。
- 教师练习记录保留筛选和回听；不新增删除、编辑或导出记录功能。
- 班级模块保留创建班级、复制班级 ID／入班码和维护学生归属；不新增班级删除功能。
- 问知音保留课程答疑、课程资料、收起与暂停动效；不恢复独立学生知识模块。
- 不新增排行榜、付费、MIDI 判音、实时错音评分或等级奖励。
