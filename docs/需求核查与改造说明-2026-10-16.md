# 知音教学需求核查与改造说明

核查依据：项目根目录《知音教学智能体学生端与教师端需求笔记.md》。本说明区分改造前已有功能、本次补齐功能和仍需外部条件的事项；不把原型、接口代码或历史截图当作生产平台验收。

## 改造前的主要差距

- 学生自传谱图尚未接通：页面只向教师开放上传，接口也禁止学生维护资源。
- 已发布谱库对所有学生展示，缺少“本班”范围。
- 本地文件上传返回相对签名地址，保存校验只接受绝对地址，可能出现上传成功、存档失败。
- 学生没有个人统计入口；教师统计周期与页面标签不一致，且可能把教师本人练习计入学生班级数据。
- “求助老师”是公开帖子，缺少直接教师私密留言；回课标记为全局值，不能按教师独立维护，也不能导出。
- 没有可维护和检索的课程知识库；聊天仅通过提示词要求不编造，并无已收录资料支撑。
- 乐谱分析仍输出“节奏密度”，把模型原样 JSON 当作结果；音名柱状图被叫作音高走向，未知值缺少规范处理。
- 地图已有中欧切换、时间线和人物对话，但缺少参考来源、时代层面的中外对照，明清无人物，切换时代可能保留旧人物对话。

## 琴谱库与个人练习

本次接通学生个人谱图上传、修改、替换、删除及自动加入“我要练”。个人资源固定为学生本人所有、未发布；其他学生及教师不能通过谱库详情或本地文件地址读取私人谱图。

按用户确认的规则，教师可对每份琴谱选择“全部班级”或指定班级。原有琴谱空范围保留全部班级语义；范围检查覆盖列表、详情、练习引用、待练列表、任务选曲和本地文件读取。

保留曲名／作曲家搜索、国内国外／难度／教师确认曲风筛选、批量上传、编辑属性、发布撤回及曲风管理。谱面预览补充缩放和全屏，沉浸练习页继续支持完整谱面滚动、50%—300%缩放、自动计时和麦克风录音、暂停继续、结束保存及失败重试。

修复本地文件保存及归属校验。新上传文件持久记录上传者；签名不替代登录和业务权限检查。练习档案展示来源、日期、开始时间、有效时长、暂停次数与录音。删除练习记录前保护已提交引用，无引用的本地录音清理文件及元数据；远端调用平台删除接口，不能据此承诺云端物理擦除。

学期目标原已有教师设置与学生进度，本次补充教师查看全体学生进度（包括零练习学生）。当前教师范围为全体学生，尚无自动识别教师授课关系的课程模型；学习通消息推送不在已实现范围。

## 任务、材料与在线评阅

原已有任务新建／编辑／关闭／删除、固定／随机选曲、面向班级／指定学生、材料必交／选交／无需提交、已交／未交名单、评分与评语回传。

本次补强：任务发布与调整时检查琴谱范围覆盖目标学生，随机候选遵循班级可见范围；材料检查文件归属、音视频类型、必交项以及不要求提交的材料；关闭任务仍可在原曲目撤回后正常执行。保留录音、文字练习记录、演奏视频分别上传和在线查看路径。

同曲目多次提交并排对比仍属原笔记的后续优化，本次未新增提交版本历史。

## 个人与班级统计

新增学生个人练琴数据入口，服务端仅查询本人。教师可按班级查看本周／本月数据；本周为北京时间周一至当天，本月为当月一日至当天，近7日趋势独立计算。

练琴频次采用有记录的天数；练习次数采用记录条数；总时长累加有效秒数；平均单次时长为总秒数除以次数。教师人均时长采用所选班级全部学生人数（含零练习者）作分母；活跃学生指周期内至少有一条练习记录的学生；参与率为活跃人数除以班级学生总数。页面明确统计仅作教学管理参考，不进入课程成绩。

统计排除教师本人练习，读取超过默认数据库页大小的记录，加载失败可重试。

## 社区、教师留言与回课重点

保留五分类发帖、点赞、评论、公开“求助老师”；新增最新／点赞最多排序、继续加载、社区智能答疑入口。

“给老师留言”由学生显式选择收件教师，仅发件人及收件教师能查看和回复。教师目录供选择，不表示系统已识别任课关系。公开求助仍是公开交流。

回课标记改为每位教师独立维护，汇总后可导出完整 TXT（问题、正文、昵称、时间与回复）。历史全局标记仅在数据库只有一位教师时安全迁移给该教师，多教师时不猜测归属。

## 课程知识、智能答疑与乐谱分析

新增“课程知识与答疑”页面。教师维护自己的知识条目：标题、正文、检索词、可选参考链接；学生查阅已收录课程资料。当前为共享课程知识库，尚未建立多课程／多学校隔离模型。教师可把学校允许使用的分析指标清单录入资料，但不自动启用未经确认的新分析算法。

聊天先检索实际知识条目；没有匹配资料时直接通过 SSE 明确返回“这部分超出已收录范围”。有资料时把课程原文与已收录地图资料提供给模型，约束其仅依据资料回答；页面显示本轮参考资料。涉及演奏水平与艺术处理，系统要求仅供参考，以教师指导为准。模型输出仍需要教学内容验收，不能把提示词约束等同于绝无错误。

乐谱分析取消节奏密度。MusicXML 从实际音符解析，常用单声部 ABC 处理调号、升降还原、八度与简单延音，计算有音高音符数、音域、音名出现次数和谱面音高走向；休止符不计入，不展开反复。MusicXML 未明确 mode 时不凭调号猜大小调；不支持的格式明确报错，不能可靠推导的和弦色彩显示未识别。

图片仍依赖外部模型逐音识别，数值由合法音符序列计算，不使用模型估计的总数或示例直方图；页面明确需要对照原谱复核。复杂多声部 ABC、宏、特殊调式等请转 MusicXML，当前不声称完整覆盖所有记谱语法。

乐曲导读补齐作品背景、作曲家背景、创作年代、所属时期、曲调五项显示。作品年代、时期与曲调仅从明确匹配该作品的课程资料提取，避免套用同作曲家另一首作品；未收录显示未识别。精确作品匹配使用条目标题或完整曲名检索词；有多个版本冲突时需教师整理资料。右侧可继续追问。

## 音乐史地图

保留中国优先与中欧统一交互。补明清朱载堉，以姓名标识代替未经核实的肖像。现收录14位人物资料，均提供来源链接；欧洲四个时代加入同期中国音乐提示与出处。时代切换清除不属于当前时代的人物，聊天由服务端根据人物 ID 读取本地资料。

来源仅支持所整理的有限史实，不表示收录完整音乐史；后续扩展应继续核查资料，不能任由模型补造人物或作品。

## 远端数据库与部署

本地 SQLite 自动补充班级范围、私信收件人、教师独立回课标记和知识库表，不删除既有数据。

远端提供增量迁移。原演示式匿名开放策略不能满足私信和学生数据权限，本次改为仅后端服务凭据访问，配套撤销匿名／普通认证角色的业务表直连权限。远端部署需配置 `CODER_SUPABASE_SERVICE_ROLE_KEY` 并执行新增迁移；缺配置返回503，不退回匿名访问。未在真实远端数据库执行迁移，生产部署前需备份并联调。

## 仍需学校资料、范围确认或外部环境验证

- 真实学习通认证中心、课程内链接和目标学习通内置浏览器联调；当前代码与本地协议测试不能替代真实账号验收。
- 学习通消息提醒推送，原笔记已注明目前无法实现。
- 游客可以访问哪些功能和数据，原笔记尚未确定。
- 学校统一曲风取值及允许使用的分析项目清单。
- Word 转谱图；PDF 当前采用浏览器原生查看，不具备转成图片后自动识别的完整链路，目标内置浏览器兼容需实测。
- 真实学生设备麦克风权限、学习通内置浏览器的视频编码／播放兼容；本地 Chromium 验收不等于全部设备适配。
- 最新开源模型、编曲生成／排练辅助所需模型资料，及多次提交并排对比。
- 精确复刻封面／页面需要额外 Figma 及明确设计稿，本次沿用已有首页与音乐厅主题。
