用户已给定首页视觉和功能范围；2026-10-15 确认环境稍后配置、教师维护班级归属。

1. 首页保留所提供黑金音乐厅场景，百分比热点连接真实模块，身份选择改为弹窗；手机展示可读的功能入口。验收：入口、身份服务错误与 AI 助教弹窗可操作。

3. 练习页使用全宽可滚动谱面、缩放与全屏，固定计时和录音状态，存档可重试；带任务参数时返回任务提交。验收：长谱完整可见、暂停同步、计时走秒、结束停止计时。
4. 独立任务页面连接教师发布、学生提交、教师评阅，支持三种受众范围与固定/随机曲目；学期目标按区间汇总时长。验收：范围过滤、必交项、关闭与截止、本人提交隔离、评分回传、学期进度。
5. 新增 Supabase SQL 迁移并保持原有 API 数据访问规范。执行类型检查、定向 lint、核心业务测试和浏览器检查。没有外部环境时只报告离线验证，不宣称真实上传或数据库联调通过。
